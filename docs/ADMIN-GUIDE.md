# Website Editor’s Guide

## Sign in

Visit `https://your-domain.com/admin/login` and enter the administrator details supplied to you. Never share the Super Admin password. Editors can manage content but should not manage security settings or accounts.

## Change website text, branding and social accounts

Open **Site Settings**. The screen is organized into Identity and Branding, Homepage Content, Biography, Contact Information, Official Social Accounts and Integrations. From here an administrator can replace the logo, favicon and homepage portrait; edit the homepage introduction, biography, daily quotation, footer and contact details; and update every official social link. Use **Save all website changes**, then open the public website to review the result. Uploaded branding images replace the previous files automatically.

The TikTok page uses TikTok's official creator-profile embed and automatically displays recent videos from the account saved in Site Settings. If the official account ever changes, replace its complete profile URL and the embed username will update automatically.

## Sync YouTube

Open **Site Settings**, enter the official YouTube channel ID and API key, and save. Return to **Dashboard** and choose **Sync YouTube now**. The site imports recent videos and refreshes views and thumbnails. It also syncs automatically every six hours. If Google reports a quota or key error, existing videos remain online; check the API key and try again later.

In **YouTube & Videos**, edit a video to feature it on the homepage or hide it from the public library. Hiding is safer than deleting because the next sync may restore a deleted video.

## Publish an article

Open **Articles → Add new**. Enter the title, write or paste the article, choose **published**, add the date and a suitable cover image, then save. Use **draft** while work is incomplete. Keep headings descriptive, add image descriptions, and paste only content you have permission to publish.

## Add an event

Open **Events → Add new**. Enter the title, date and time, venue, description, and optional image. Double-check the time and location before saving. Past events automatically remain available as an archive.

## Upload audio, books, and gallery albums

Use **Audio Library** for MP3 files and **Books** for PDFs or legitimate purchase links. Compress large files before uploading to preserve hosting space. Add clear titles and descriptions. Gallery albums organize event photography; use accurate image descriptions for accessibility.

## Respond to messages

Open **Contact Messages**. Unread messages have a dot. Opening a message marks it read. Choose **Reply by email** to answer in your normal email application. Delete spam only after confirming it is not a genuine enquiry.

## Good publishing habits

- Preview spelling, dates, Arabic/Hausa diacritics, links, and mobile readability.
- Use images you own or are licensed to publish.
- Never upload passwords, private correspondence, identity documents, or executable files.
- Keep a local backup of important original audio, images, and PDFs.
- Contact the Super Admin before changing API, domain, analytics, or security settings.
